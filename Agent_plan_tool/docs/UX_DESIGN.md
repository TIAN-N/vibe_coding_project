# UX 设计

## 页面结构

```text
┌─────────────────────────────────────────────────────────────────────┐
│ CoNET 拓扑工程平台                       数据版本 / 刷新版本          │
├───────────────┬───────────────────────────────────────┬─────────────┤
│ 左侧控制栏     │ 逻辑拓扑画布                           │ 指标看板     │
│ 上传数据       │                                       │ 默认展开     │

├───────────────┴───────────────────────────────────────┴─────────────┤
│ 底部数据抽屉：网元表 / 链路表 / 环链表                                │
└─────────────────────────────────────────────────────────────────────┘
```

## 看板指标扩展方式

第一版内置基础统计指标，同时提供 JSON 指标模板输入框。后续接入大模型时，推荐流程是：

1. 用户用自然语言描述想看的指标。
2. 大模型读取当前表字段和样例值。
3. 大模型生成声明式指标 JSON。
4. 后端 `/api/v1/metrics/custom` 解释执行。
5. 用户满意后保存到 `/api/v1/metrics/templates`。

这样既保留大模型灵活性，也避免执行动态代码带来的安全风险。
